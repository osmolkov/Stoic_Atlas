# Stoic_Atlas

Интерактивный атлас учения стоицизма: основные понятия, граф знаний, хронология, мыслители, добродетели и упражнения.

## Публикация

Статический сайт для GitHub Pages. Входная страница — `index.html`; стили и скрипты — в `assets/`. В `CNAME` настроен домен `stoicatlas.ru`.

## Книги на русском языке

Раздел «Библиотека атласа → Книги на русском языке» отображается через `assets/books.js` и `assets/books.css`:

- Девять авторских карточек, фильтры «Античные тексты» и «Современные авторы».
- Литрес — ссылки на электронные издания; «Читай-город» — карточки бумажных изданий либо каталог автора, если точное издание не подтверждено; «Лабиринт» — дополнительная ссылка на подходящее издание Марка Аврелия.
- Дополнительные ссылки на общедоступные англоязычные тексты для античных авторов.
- Изображения обложек стилизованы средствами CSS и не являются издательскими обложками.

**Все ссылки сейчас обычные, без реферальных параметров и без начисления комиссии.** Цены и наличие на сайте не показываются, поскольку они меняются.

После принятия в официальную партнёрскую программу можно заменить URL в массиве `books` внутри `assets/books.js` **только на выданные конкретному участнику ссылки**. Сохраняйте сопоставление книг, авторов и магазинов; согласуйте обязательную маркировку и иные условия программы до размещения партнёрских ссылок.

## Источники

Утверждения об истории и учении сопровождены ссылками на первоисточники или академические материалы. Более поздние интерпретации отделены от античной школы.
